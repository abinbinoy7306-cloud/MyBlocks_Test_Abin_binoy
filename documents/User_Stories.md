# User Stories

*Date Updated: November 19, 2026, 21:20 IST*

## Super Admin
- **US001**: As a Super Admin, I want to create a new firm (tenant) so that a new company can start using the platform.
- **US002**: As a Super Admin, I want to deactivate a firm so that inactive customers no longer consume resources.
- **US003**: As a Super Admin, I want to view system‑wide analytics across all firms.

## Firm Admin
- **US101**: As a Firm Admin, I want to configure country and currency settings for my firm.
- **US102**: As a Firm Admin, I want to manage users (create, update, delete managers and team members).
- **US103**: As a Firm Admin, I want to view a firm‑specific dashboard showing key metrics.

## Manager
- **US201**: As a Manager, I want to approve or reject team member requests.
- **US202**: As a Manager, I want to generate reports for my team's performance.

## Team Member
- **US301**: As a Team Member, I want to view my task list and submit completed work.
- **US302**: As a Team Member, I want to access contextual help via the "?" icons.

*All user stories are scoped for the NCLC multi‑tenant platform.*
