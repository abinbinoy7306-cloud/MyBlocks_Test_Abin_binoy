# Use Cases

*Date Updated: November 19, 2026, 21:20 IST*

## 1. Super Admin Management
- Create, update, delete firms (tenants).
- Assign firm admins.
- View system-wide analytics.

## 2. Firm Admin Workspace
- Manage firm profile, localization, tax settings.
- Manage users (managers, team members).
- Access firm-specific dashboards.

## 3. Manager Operations
- View team performance.
- Approve/reject requests.
- Generate reports.

## 4. Team Member Tasks
- Access task list, submit work.
- View help texts via "?" icons.

## 5. Multi‑Country & Multi‑Currency
- Configure country‑specific settings.
- Handle invoices in multiple currencies.

*All use cases are scoped for the NCLC multi‑tenant platform.*
